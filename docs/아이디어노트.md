개인용 PC 노트 앱 아이디어 노트

작성일: 2026-10-25 상태: 아이디어 단계 (설계 전)

1. 한 줄 요약

Notion을 벤치마킹한 타이핑 전용 개인용 PC 노트 앱을 직접 만든다. 인터넷에 연결되어 있을 때만 Claude API로 AI 어시스트를 제공하고, 오프라인에서는 편집만 정상 동작한다.

2. 배경과 결정 사항
손글씨 필기는 범위에서 제외한다. 타이핑만 지원한다.
기존 앱(Notion, Obsidian 등)을 그대로 쓰는 대안도 검토하였으나, 직접 만들기로 한다.
사용 대상은 본인 한 명이며, 배포는 현재 계획에 없다.
AI는 Claude API를 사용하며, Claude Max 플랜에 포함된 월간 API 크레딧으로 비용을 충당한다.
Claude Console 조직을 플랜에 연결해야 크레딧을 받을 수 있다. 연결한 조직은 이후 직접 변경할 수 없다.
이 크레딧은 Claude 앱·Claude Code의 사용 한도와 별개이며, 소진되면 다음 월간 지급 시까지 API 요청이 중단된다.
정확한 금액과 만료일은 Console의 Billing > Promotional credits에서 확인한다.

3. 벤치마킹 조사 요약

타이핑 기반 노트 앱에서 공통으로 확인된 기능 범주는 다음과 같다.

범주 | 참고 앱 | 비고
블록 편집기 | Notion | 문단, 제목, 표, 토글 등을 블록 단위로 이동·조합
마크다운·로컬 파일 | Obsidian, Logseq, Joplin | 노트가 로컬 파일로 남아 이식성이 높음
양방향 링크·그래프 | Obsidian, Logseq | 지식 연결 기능
속성·데이터베이스 뷰 | Notion, Obsidian(Bases) | 표, 보드, 캘린더 등
전체 검색 | Evernote 등 | PDF와 이미지 내부 텍스트까지 검색
빠른 이동 | Obsidian | 빠른 전환기, 명령 팔레트
오프라인 | Notion | 데스크탑·모바일 앱에서 페이지를 내려받아 사용. 기기별 설정이며 일부 블록은 제한됨

4. MVP 범위

포함:
페이지 트리(폴더 또는 중첩 페이지)
블록 편집(제목, 목록, 체크리스트, 코드, 표, 이미지)
전체 텍스트 검색
자동 저장
마크다운 내보내기
AI 사이드 패널 (아래 5절)

제외 (후순위):
데이터베이스 뷰
실시간 협업
웹 클리퍼
모바일 동기화
플러그인 시스템
손글씨, 펜 입력

5. AI 어시스트 설계

기능 후보:
선택한 텍스트 요약
문장 다듬기·재작성
현재 노트에 대한 질문과 답변
태그 제안

모델 선택 (API 모델 문자열):
가벼운 작업: claude-haiku-5-5
긴 노트 분석, 글쓰기: claude-sonnet-5-5

동작 원칙:
오프라인이면 AI 버튼을 비활성화한다. API 호출 실패가 편집에 영향을 주어서는 안 된다.
AI는 어디까지나 부가 기능이다. 앱의 기본 동작은 AI 없이 완결되어야 한다.
호출 횟수와 입력 길이에 상한을 두어 크레딧의 갑작스러운 소진을 막는다.
비밀번호나 개인정보가 담긴 노트는 AI 전송에서 제외할 수 있는 설정을 둔다.

6. 기술 방향 (후보, 미확정)
앱 셸: Electron 또는 Tauri. 용량과 메모리는 Tauri가, 자료와 생태계는 Electron이 유리하다.
UI: React
편집기: 직접 구현하지 않고 TipTap(ProseMirror 기반), BlockNote, Lexical 중 하나를 사용한다.
저장소: 로컬 우선. SQLite 또는 마크다운 파일 중 선택한다.
마크다운 파일: 이식성과 단순성이 좋고 Obsidian 방식과 유사
SQLite: 검색과 구조화된 쿼리에 유리
보안: API 키는 소스에 넣지 않고 운영체제 키체인에 저장한다. 저장소에 올리지 않는다.

7. 미결 사항
앱 셸: Electron과 Tauri 중 무엇으로 갈 것인가
편집기 라이브러리: TipTap, BlockNote, Lexical 비교와 선정
저장 방식: 마크다운 파일과 SQLite 중 선택, 또는 병행
AI 기능의 우선순위 (요약, 다듬기, 질의응답 중 무엇부터)
향후 배포 여부 (배포한다면 API 키 처리 구조를 다시 설계해야 함)
