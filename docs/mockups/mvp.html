안건

이번 주는 편집기 기본 블록과 저장 구조를 맞춘다. 검색은 trigram 색인으로 가고, 두 글자 이하는 따로 처리한다.

  • TipTap 기본 블록 연결
    • 제목·목록·체크리스트 먼저
  • SQLite 저장과 자동 저장 1초
  • 시험 빌드 메모리 재기
  • / 메뉴 항목 정리
  • 휴지통 복원 위치 규칙 확인

결정

  1. 저장은 SQLite 한 파일로 한다.
  2. 이미지는 첨부 폴더에 복사하고 본문에는 파일 이름만 둔다.
// 마지막 입력 1초 뒤, 길어도 5초마다 저장
