- 판: v0.1 (2026-10-26, NOTE-design, 작업 P1-2)
- 근거: [기능정의.md](기능정의.md) F-01~F-08, NF-01·NF-04·NF-06 / [결정기록.md](결정기록.md) D-01~D-14
- 목업: [mockups/mvp.html](mockups/mvp.html) — 브라우저로 열고 주소 끝의 `#보기`로 화면을 바꾼다(아래 표의 "목업" 열). `?theme=dark`로 다크, `?ai=closed`로 AI 패널을 닫은 모습을 본다.
- 토큰: [`src/styles/tokens.css`](../src/styles/tokens.css) — 화면의 색·글꼴·간격·모서리·그림자·움직임은 모두 이 변수로만 쓴다.
- 판 규칙: 화면 내용이 바뀔 때만 새 판을 낸다. 단계 중에 생긴 변경은 맨 아래 "개정 대기"에 모았다가 단계 끝에 한 번에 반영한다.

## 설계 방향

- **매일 켜 두는 작업 도구.** 장식보다 읽기·찾기·고치기가 빠른 화면. 중립 회색 두 겹(종이색 편집 영역 + 한 단계 어두운 사이드바·AI 패널)에 강조색은 먹청록 하나만 쓴다. 강조색은 주 버튼, 지금 위치(열린 페이지·선택), 포커스, 끌기 위치선에만 쓴다.
- **밀도.** UI 글자 13~14px, 트리 행 28px, 버튼 30px. 본문만 16px·줄 간격 1.7로 넉넉하게 둔다(한글 가독성).
- **Windows 데스크탑에 익숙하게.** 창 틀은 Windows 기본 제목 표시줄을 쓴다(Tauri `decorations: true`). 글꼴은 Segoe UI + 맑은 고딕. 맥락 메뉴는 오른쪽 클릭과 `⋯` 버튼 둘 다로 연다.
- **AI는 덧붙임.** AI 패널을 닫아도 화면이 완결된다. AI 상태(키 없음·오프라인·상한)는 패널 안에서만 알리고 편집 영역을 막지 않는다(F-08 실패 격리).
- **모달은 되돌리기 어려운 일에만.** 삭제 확인(S-03)과 내보내기(S-11)만 대화상자다. 휴지통·설정은 가운데 영역에 여는 화면이다. 검색(S-05)은 입력에 집중해야 해서 겹치는 창으로 둔다.

## S-01 앱 셸

```
┌ Windows 제목 표시줄 (wy-note) ──────────────────────────────────────────┐
│ 사이드바 248px     │ 위 막대 44px: 경로 · 저장 상태 · [AI] · [⋯]   │ AI 340px │
│ wy-note       [◧] │──────────────────────────────────────────────│ AI  12/50 ✕│
│ [검색   Ctrl K]   │                                              │ 요약|다듬기|질문│
│ + 새 페이지        │      페이지 제목 (34px)                      │          │
│ 페이지             │      본문 최대 720px, 왼쪽 72px 손잡이 자리     │ 대화     │
│  ▾ 업무            │                                              │          │
│    ▾ 회의록        │                                              │          │
│      ■ 10월 4주…   │                                              │ [입력창] │
│ ─────────────     │                                              │          │
│ 휴지통 3 / 설정    │                                              │          │
└───────────────────┴──────────────────────────────────────────────┴──────────┘
```

- 배치: CSS grid 3열(`--sidebar-width` / 나머지 / `--ai-panel-width`).
- 사이드바: 오른쪽 경계를 끌어 200~360px. `Ctrl+\`로 접기·펴기(접으면 0px, 위 막대 왼쪽에 펴기 버튼이 나온다). 너비·접힘 상태는 다시 시작해도 유지한다(F-07의 창 상태와 같이 저장).
- AI 패널: **접기 가능.** 위 막대의 `AI` 토글 버튼, 패널의 `✕`, `Ctrl+J`로 연다·닫는다. 닫으면 0px(얇은 띠도 남기지 않는다). 왼쪽 경계를 끌어 300~480px. 열림 상태는 다시 시작해도 유지한다. API 키가 없어도 패널은 열리고 안내를 보여 준다(S-07).
- 위 막대(편집 영역): 경로(조상 페이지 이름, 누르면 그 페이지로 이동) · 저장 상태 · `AI` 토글 · 페이지 메뉴 `⋯`.
  - 저장 상태(F-05): `● 저장됨`(초록 점) / `● 저장 중`(회색 점) / `● 저장 안 됨`(빨강, S-10). 글자 12px, 3단계 색.
  - 페이지 메뉴 `⋯`: 하위 페이지 추가 · 마크다운으로 내보내기(S-11) · AI 전송 제외(켜짐 표시) · 휴지통으로 이동. 트리 맥락 메뉴(S-02)와 같은 항목·같은 순서.
- 창 최소 크기 제안: 900 × 600px. 창이 1100px보다 좁아지면 AI 패널이 열려 있을 때 편집 영역 좌우 여백(`--editor-gutter`)을 40px로 줄인다. 그래도 본문이 480px 밑이면 AI 패널을 편집 영역 위에 겹쳐 띄운다(그림자 `--shadow-dialog`).
- 단축키(전역): `Ctrl+N` 새 페이지, `Ctrl+K` 검색, `Ctrl+\` 사이드바, `Ctrl+J` AI 패널, `Ctrl+,` 설정.

## S-02 페이지 트리

- 행: 높이 28px, 들여쓰기 단계마다 16px, 14px 글자, 2단계 글자색. 왼쪽부터 `펼침 화살표(20px)` · `이름` · (AI 전송 제외면 눈 가림 아이콘) · hover 때만 `⋯` `+`.
  - 하위 페이지가 없으면 화살표 자리는 비워 둔다(이름 줄이 맞도록).
  - 이름이 빈 페이지는 "제목 없음"을 3단계 색으로 보인다(F-01.2).
  - 긴 이름은 한 줄 말줄임. hover하면 전체 이름 툴팁.
- **지금 열린 페이지 강조**(F-01): 배경 `--color-bg-selected`(옅은 먹청록) + 글자 1단계 색·굵게. 그 페이지의 조상이 접혀 있으면 열 때 자동으로 펼친다.
- 펼치기·접기: 화살표 클릭, 또는 키보드 →/←. 화살표가 90° 도는 움직임 120ms. 상태는 다시 시작해도 유지(F-01).
- **만들기**(F-01.1): 사이드바 `+ 새 페이지`(최상위 맨 아래) 또는 행의 `+`(그 페이지의 하위 맨 아래, 부모를 펼침). 새 페이지가 "제목 없음"으로 생겨 열리고 커서가 페이지 제목에 놓인다.
- **이름 바꾸기**(F-01.2): 맥락 메뉴 "이름 바꾸기" 또는 `F2` → 행 안에서 바로 입력칸(먹청록 테두리). `Enter` 확정, `Esc` 취소, 바깥 클릭 확정. 페이지 제목을 고쳐도 트리에 바로 반영.
- **맥락 메뉴**: 오른쪽 클릭 또는 `⋯`. 항목: 하위 페이지 추가 / 이름 바꾸기 `F2` / 마크다운으로 내보내기 / ─ / AI 전송 제외 ✓ / ─ / 휴지통으로 이동 `Del`(빨강).
- **끌어 옮기기**(F-01.4)
  - 끄는 행은 투명도 45%로 남고, 커서 옆에 이름 고스트(떠 있는 그림자 `--shadow-drag`)가 따라온다.
  - 놓을 위치 표시: 행의 위·아래 1/4 구간이면 **사이**에 놓기 → 2px 먹청록 선(왼쪽 끝 작은 원, 놓일 단계의 들여쓰기에서 시작). 가운데 1/2 구간이면 **안으로**(하위로) 놓기 → 그 행 전체를 옅은 먹청록 + 1px 테두리.
  - 접힌 행 위에 0.6초 머물면 펼친다. 목록 위·아래 끝에 가면 자동 스크롤.
  - 자기 자신과 자기 하위로는 놓을 수 없다: 표시가 나오지 않고 커서가 금지 모양.
  - `Esc`로 끌기 취소.
- 키보드: ↑/↓ 행 이동, →/← 펼침·접힘(또는 부모로), `Enter` 열기, `F2` 이름 바꾸기, `Del` 삭제(S-03), `Shift+F10`/메뉴 키로 맥락 메뉴. ARIA `tree`/`treeitem`/`group`, `aria-expanded`, `aria-selected`.
- 사이드바 아래: `휴지통`(옆에 개수) · `설정`. 휴지통·설정 화면이 열려 있으면 그 행을 강조하고 트리 강조는 끈다.

## S-03 삭제 확인

- 트리·페이지 메뉴의 "휴지통으로 이동" 또는 `Del`.
- 대화상자(420px, 모서리 12px). 제목 `"회의록"을 휴지통으로 옮길까요?`. 하위가 있으면 본문에 `하위 페이지 2개도 함께 옮겨집니다.`(개수 굵게, F-01.3). 이어서 `휴지통에서 언제든 복원할 수 있습니다.`
- 버튼: `취소` / `휴지통으로 이동`(빨강 채움, 처음 포커스). `Esc` 취소.
- 하위가 없는 페이지도 같은 창을 쓴다(실수 방지. 하위 개수 문장만 뺀다).
- 옮긴 뒤: 열려 있던 페이지면 트리의 바로 위 형제(없으면 부모, 없으면 첫 페이지)를 연다. 아래쪽에 알림 `"회의록"을 휴지통으로 옮겼습니다 [실행 취소]`를 5초 보인다(실행 취소 = 바로 복원).

## S-04 휴지통

- 사이드바 `휴지통` → 가운데 영역에 연다(최대 760px).
- 머리: 제목 "휴지통" + 설명 `복원하면 원래 위치로 돌아갑니다. 영구 삭제 전까지 첨부 이미지도 남아 있습니다.` + 오른쪽 `휴지통 비우기`(빨강 글자 버튼).
- 목록 행(지운 시각 최신순): 페이지 이름(굵게) · `하위 n개` 배지 · 아래 줄에 원래 위치 경로(3단계 색) · 지운 날짜 · `복원` `영구 삭제`.
  - 하위 페이지는 부모와 한 줄로 묶어 보인다(복원·영구 삭제도 함께).
  - 원래 부모가 영구 삭제되었으면 경로 자리에 `최상위 (원래 위치 "임시"가 영구 삭제됨)`(F-01.3).
- 복원: 바로 실행, 알림 `"옛 회의 메모"를 복원했습니다 [열기]`.
- 영구 삭제·휴지통 비우기: 확인 창(S-03 모양, 버튼 `영구 삭제`). 문구 `"옛 회의 메모"와 하위 페이지 2개, 첨부 이미지를 지웁니다. 되돌릴 수 없습니다.`
- 빈 휴지통: `휴지통이 비어 있습니다.` 한 줄, `휴지통 비우기` 비활성.

## S-05 검색

- `Ctrl+K` 또는 사이드바 검색칸 → 화면 위쪽(12vh)에 600px 창, 뒤는 옅은 막(`--color-overlay`). 입력칸에 바로 포커스.
- 입력하면 바로 결과(입력 멈춘 뒤 120ms). 결과 행: **페이지 제목** · 오른쪽에 트리 경로(3단계 색, 말줄임) · 아래 줄에 일치 부분이 들어간 본문 일부 2줄(F-04). 일치 글자는 노란 바탕 `--color-mark`, 글자색 1단계.
- 키보드: ↑/↓ 고르기(선택 행 배경 `--color-bg-selected`), `Enter` 열고 첫 일치 위치로 스크롤, `Esc` 닫기. 마우스 클릭도 같다. 아래 막대에 조작 안내와 결과 수.
- 상태
  - 빈 입력: 최근 연 페이지 5개(검색 전 빠른 이동).
  - 결과 없음: `"회의룩"과 일치하는 페이지가 없습니다.` (휴지통 페이지는 찾지 않는다는 말은 넣지 않는다 — 결과 없음이 잦을 때 개정 대기로 다시 본다.)
  - 1~2글자 검색어도 같은 화면(F-04 LIKE 경로). 0.5초 넘게 걸리면 입력칸 오른쪽에 작은 진행 표시.
- 열린 페이지에서 일치 위치는 1.5초 동안 `--color-mark`로 깜빡이지 않고 옅게 강조했다가 사라진다.

## S-06 편집 영역·블록

- 페이지 제목: 34px 굵게. 빈 제목은 자리표시 "제목 없음". 제목에서 `Enter`는 본문 첫 블록으로.
- 본문: 16px / 줄 간격 1.7 / 최대 720px(한 줄 한글 약 45자). 블록 사이 2px, 제목 블록 위는 더 띄운다(제목 1 32px, 제목 2 24px, 제목 3 20px).
- 빈 문단의 자리표시(커서가 있을 때만): `/를 입력해 블록 종류를 고르세요`.
- **블록 손잡이**(F-02.7): 블록에 마우스를 올리면 본문 왼쪽 바깥(52px 떨어진 곳)에 `+`(아래에 새 블록 + / 메뉴)와 `⋮⋮`(끌기) 두 버튼이 3단계 색으로 나타난다(120ms). 커서가 있는 블록에도 같은 손잡이가 보인다(키보드만 쓸 때도 위치를 알 수 있게). 첫 줄 높이에 세로 가운데 맞춤.
  - `⋮⋮` 클릭: 블록 선택(옅은 먹청록 바탕) + 블록 메뉴(종류 바꾸기 / 위로 `Alt+↑` / 아래로 `Alt+↓` / 복제 / 삭제).
  - `⋮⋮` 끌기: 블록 사이에 2px 먹청록 위치선, 끄는 블록은 반투명.
  - 키보드 `Alt+↑/↓`: 커서가 있는 블록을 옮긴다. 옮긴 블록이 화면 밖이면 따라 스크롤.
- 블록 모양(F-02.1~F-02.6)
  - 제목 1·2·3: 28 / 23 / 19px, 줄 간격 1.3, 굵게(제목 3은 600).
  - 글머리 목록: 들여쓰기 24px, 2단계 이하는 빈 원. 번호 목록 숫자·글머리는 2단계 색.
  - 체크리스트: 16px 네모(모서리 3px). 체크하면 먹청록 채움 + 흰 체크, 글자는 3단계 색 + 취소선. 네모 클릭으로 바꾼다.
  - 인라인 코드: 고정폭 0.875em, 바탕 `--color-bg-sunken`, 글자 빨강 계열.
  - 코드 블록(F-02.4): 바탕 `--color-bg-sunken`, 1px 선, 모서리 6px. 위 왼쪽에 언어 선택(누르면 언어 목록 + 검색), 오른쪽에 복사. 고정폭 13.5px / 1.6, Tab 2칸. 문법 강조는 `--code-*` 토큰 7색만. 주석도 기울이지 않는다(한글 글꼴에는 기울임꼴이 없어 억지로 비스듬히 그려진다).
  - 표(F-02.5): 1px 선, 머리 행 바탕 사이드바 색·굵게·2단계 색, 셀 여백 6×8px, 14px. 숫자 열은 오른쪽 정렬·같은 폭 숫자. 표에 마우스를 올리면 아래·오른쪽에 `+` 띠(행 추가·열 추가). 셀 오른쪽 클릭 메뉴: 위/아래 행 추가, 왼/오른 열 추가, 행 삭제, 열 삭제. 선택한 셀은 2px 먹청록 안쪽 선.
  - 이미지(F-02.6): 본문 폭에 맞춤(원본보다 키우지 않음), 모서리 6px, 1px 선. 클릭하면 2px 먹청록 테두리 + 양옆 크기 손잡이. 아래 캡션(3단계 색, 선택 사항). 첨부 파일이 없으면 점선 상자에 `이미지 파일을 찾을 수 없습니다: 파일이름`.
  - 링크: 먹청록 밑줄(두께 1px, 3px 띄움).
- 붙여넣기·끌어 놓기로 이미지를 넣는 중에는 그 자리에 같은 크기의 회색 자리(`--color-bg-sunken`)를 보인다.

## S-07 AI 패널

- 머리: `AI` · `오늘 12 / 50`(하루 호출/상한, 같은 폭 숫자) · `✕`.
- 작업 탭(세그먼트): `요약` · `다듬기` · `질문`.
  - 요약(F-08.1): 대상 줄 `대상: 선택 영역 · n자` + `요약하기` 버튼. 선택이 없으면 버튼 비활성 + `본문에서 요약할 부분을 선택하세요`.
  - 다듬기(F-08.2): 결과 카드에 `원문`(2단계 색)과 `다듬은 글`을 위아래로 나란히. 버튼 `바꾸기`(주 버튼) · `삽입` · `복사`.
  - 질문(F-08.3): 대상 줄 `대상: 이 페이지 전체 · n자`(선택 영역이면 `대상: 선택 영역 n자`). 질문은 오른쪽 말풍선(옅은 회색), 답은 왼쪽 그냥 글 + `삽입` `복사`. 아래 입력창(여러 줄, `Enter` 보내기 / `Shift+Enter` 줄바꿈), 아래 줄 왼쪽 안내, 오른쪽 `새 대화`. 받는 중에는 점 3개 표시 + 보내기 자리에 `중지`.
  - 앞 대화를 뺐을 때: 대화 맨 위에 `앞 대화 n개는 이번 질문에 포함되지 않음`(3단계 색, 가운데).
- 결과를 반영하기 전에는 본문이 바뀌지 않는다. `바꾸기`·`삽입` 후 `Ctrl+Z`로 되돌린다(F-08).
- 상태 알림(패널 본문 위, 한 번에 하나, 우선순위 순). 이 상태에서는 작업 버튼·입력창이 비활성.
  1. **API 키 없음**(F-08.6): 회색 알림 + `설정 열기`.
  2. **AI 전송 제외 페이지**(F-08.5): 회색 알림, 입력창 자리표시 `AI 전송 제외 페이지입니다`.
  3. **오프라인**(F-08): 노랑 알림 `인터넷에 다시 연결되면 자동으로 켜집니다.` 머리의 사용량 자리에 `오프라인` 배지.
  4. **오늘 상한 도달**(F-08.5): 노랑 알림 + 남은 시간.
  5. **2만 자 초과**(F-08.3, F-08.5): 회색 알림 `질문할 부분을 본문에서 선택하세요. 자동으로 잘라 보내지 않습니다.`
  - 호출 실패(시간 초과·네트워크·키 오류): 결과 자리에 빨강 알림 + 이유 + `노트는 바뀌지 않았습니다.` + `다시 시도`.
  - 크레딧 소진: 빨강 알림 `이번 달 크레딧 소진`(F-08).
- 페이지를 바꾸면 그 페이지의 대화로 바뀐다(F-08.3).

## S-08 설정

- 사이드바 `설정` 또는 `Ctrl+,` → 가운데 영역(최대 760px). 위에 구역 탭 `일반` `AI`(한 화면 스크롤로도 다 보이는 길이라 탭은 위치 이동만 한다).
- 행 배치: 왼쪽 200px 이름, 오른쪽 조작 + 도움말(12px, 3단계 색).
- 화면 › 테마: 세그먼트 `Windows 설정 따름`(기본) · `라이트` · `다크`. 바꾸면 바로 적용.
- 데이터(NF-01): 설명 `노트·이미지·설정이 모두 이 폴더 하나에 있습니다. 앱을 끈 뒤 폴더를 통째로 복사하면 백업입니다.` 경로는 고정폭 글자로 회색 바탕 상자(긴 경로는 말줄임 + 툴팁) + `폴더 열기`(탐색기).
- AI › Claude API 키(F-08.6)
  - 키 없음: 입력칸(`password`, 자리표시 `sk-ant-로 시작하는 키 붙여넣기`) + `확인`(시험 호출) + `저장`. 붙여넣기 전에는 둘 다 비활성, 붙여넣으면 `확인` 활성, 확인되면 `저장`이 주 버튼으로 활성. 오프라인이면 `확인` 비활성 + 도움말 `오프라인에서는 확인할 수 없습니다`.
  - 확인 실패: 입력칸 아래 빨강 글 `키를 확인하지 못했습니다: 잘못된 키입니다.`
  - 키 있음: `🔑 ••••••••••••7Qx2`(끝 4자리만) + `확인됨` + `바꾸기` · `삭제`(빨강 글자). 삭제는 확인 창.
- AI › 하루 호출 상한(F-08.5): 숫자 입력(88px, 오른쪽 정렬) `회 · 오늘 12회 사용`. 1~1000.
- AI › 한 번에 보내는 글자 수: `최대 20,000자`(바꿀 수 없음, 기능정의 F-08.5는 호출 상한만 바꿀 수 있게 정함).
- AI › 사용 기록: 표(날짜 · 호출 · 보낸 글자), 최근 30일. `노트 내용은 기록하지 않습니다.`
- 저장 버튼 없음. 바꾸면 바로 저장하고 행 오른쪽에 `저장됨`을 1.5초 보인다.

## 공통 규칙

- **포커스**: 모든 조작 요소에 `:focus-visible` 2px 먹청록 테두리(2px 띄움). 입력칸은 테두리 색이 먹청록으로 바뀌고 1px 바깥선.
- **상태**: 버튼은 기본 · hover(바탕 6% 어둡게) · 눌림(10%) · 비활성(글자 38% 투명, 커서 금지) · 진행 중(글자 대신 작은 진행 표시, 폭 유지).
- **알림(토스트)**: 화면 아래 가운데, 진한 바탕(본문 글자색) + 밝은 글자, 동작 버튼 1개, 5초. 겹치면 마지막 것만.
- **움직임**: hover 120ms, 메뉴·패널 열기 180ms, 감속 곡선 `--ease-out`. 화면을 그릴 때 차례로 나타나는 연출 없음. Windows "애니메이션 효과" 끄기(`prefers-reduced-motion`)면 이동은 없애고 짧은 투명도 변화만.
- **아이콘**: 16px, 24 격자, 선 1.6, 끝 둥글게. 모두 같은 묶음에서(아래 "남은 결정" 1).
- **글자 선택·스크롤바**: 선택 바탕은 먹청록 18%, 스크롤바는 얇게 선 색(tokens.css 아래 기본값).
- **문구**: 버튼은 하는 일을 쓴다(`휴지통으로 이동`, `복원`, `바꾸기`). 오류는 무엇이 안 됐는지 + 지금 상태 + 할 수 있는 일.

### 글꼴

- 기본: Windows 기본 글꼴만(설치·라이선스·용량 0). 라틴 Segoe UI, 한글 맑은 고딕, 코드 Cascadia Mono → 없으면 Consolas(이 PC는 Windows 10이라 Cascadia가 없을 수 있음).

  - 코드용 선택: D2Coding(SIL OFL 1.1, 한글 고정폭). 필요하면 같은 방식.

목업(`docs/mockups/mvp.html`)과 토큰(`src/styles/tokens.css`)을 `/impeccable audit` 기준으로 점검했다. 제품 맥락 문서(PRODUCT.md)는 사용자 면담이 필요해 만들지 않고 이 문서와 기능정의를 기준으로 삼았다.

| 항목 | 점수 | 요점 |
|---|---|---|
| 접근성 | 3/4 | 텍스트 대비 AA 통과(라이트·다크), `:focus-visible` 공통, 트리·대화상자·상태 알림 ARIA 지정. 손잡이·아이콘 버튼 24px은 마우스 전용 데스크탑이라 허용 |
| 성능 | 4/4 | 움직임은 색·불투명도·회전만(120~180ms), 레이아웃 속성 애니메이션 없음, 원격 자원 없음 |
| 테마 | 4/4 | 색은 모두 토큰(예외: 알림 토스트 hover 중립 회색 1곳). 다크는 실제 렌더링으로 확인 |
| 창 크기 | 3/4 | 1440×900, 1000×700(AI 패널 닫힘)에서 깨짐 없음. 900px 미만 규칙은 남은 결정 4 |
| 구현 일관성 | 4/4 | 탐지기 0건(의도한 예외 2건은 목업 머리에 이유와 함께 표시) |
| **합계** | **18/20** | 우수 |

- 렌더링 확인: 헤드리스 Edge로 16장(보기 12개 + 다크 3개 + 좁은 창 1개).
- 렌더링하면서 고친 것:
  - 목업의 보기 전환 규칙이 요소를 브라우저 기본 표시로 되돌려 AI 패널의 flex 배치가 풀려 있었다.
  - `/` 메뉴의 제목 1·2·3 아이콘이 같았다 → H1·H2·H3 글자로 바꿨다.
  - 다듬기 결과 카드가 높이 0으로 줄어 있었다.
  - 코드 주석이 기울임꼴이었다 → 기울이지 않게 바꿨다.
  - 끌기 그림자가 이름 입력칸을 가리고 있었다.
- 구현 때 지킬 것(P2):
  - 다크 모드 QA: 코드 강조 7색과 `--color-mark`는 실제 TipTap 화면에서 다시 본다.
  - 목업의 화면 ID 표시는 목업 전용이다. 앱에 넣지 않는다.

## 남은 결정

1. **아이콘 묶음**: 직접 그린 SVG(목업 방식, 의존성 없음) vs `lucide-react`(ISC 라이선스, 쓰는 것만 번들). 새 라이브러리라 사용자 결정. 추천: lucide-react — 아이콘 30여 개를 직접 유지하는 비용이 크고, 목업 아이콘도 같은 격자·선 굵기(24, 1.6)라 바꿔도 모양이 맞는다.
2. **Pretendard 포함 여부**: 위 "글꼴". 추천: MVP는 시스템 글꼴로 시작, 화면이 나온 뒤 비교해서 결정(토큰 한 줄이라 되돌리기 싸다).
3. **단축키 제안 확정**: `Ctrl+J`(AI 패널), `Ctrl+\`(사이드바), `Ctrl+N`(새 페이지), `Ctrl+,`(설정), `F2`·`Del`(트리). D-11에 없는 것들이다.
4. **창 최소 크기 900 × 600px**와 좁은 창에서 AI 패널을 겹쳐 띄우는 규칙(S-01).
