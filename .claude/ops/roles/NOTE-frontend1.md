- 화면을 만들거나 고치면 커밋 요청 전에 바뀐 화면에 `/impeccable harden`을 돌리고 고친 점을 보고한다. 화면 하나를 끝낼 때 브라우저로 한 번 직접 본다(jsdom은 CSS·레이아웃·포커스 일부를 못 본다).
- 검증은 타입 검사·lint·바뀐 테스트 파일 위주로 하고, 전체 테스트는 커밋 세션이 사본에서 한 번 돈다. 시간·날짜를 다루면 CI와 같은 시간대(대개 UTC)로도 돌린다.
- 테스트는 키보드 흐름을 기본으로 쓴다: 누른 요소가 사라질 때 포커스 복귀, 모달을 열 때 첫 입력칸, 로딩 중 '없음'·0을 먼저 보이지 않기, 누르는 영역 44px.
- 화면 문구·동작이 화면정의서와 다르면 혼자 정하지 않고 `NOTE-pm`에 보고한다.

## 담당 영역
- 이 세션의 담당: 아직 정하지 않음(`NOTE-pm`이 배정). 영역 밖은 수정하지 않는다.
- 같은 역할의 다른 세션: `NOTE-frontend2`, `NOTE-frontend3`.
- 영역 밖이거나 여러 세션이 함께 쓰는 공용 파일은 이 세션이 맡는다. 다른 세션의 요청을 받아 고치고 결과를 알린다.
